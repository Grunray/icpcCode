# 01外部指标题解与实现说明

## 题目核心点
- 用外部指标评估聚类性能：`JC`（Jaccard 系数）、`FM`（Fowlkes–Mallows 指数）、`Rand`（Rand 指数）。
- 外部指标通过比较聚类结果与参考标签的样本对一致性来度量质量，依赖四类样本对计数：`a, b, c, d`。

## 题目要求（你要做什么）
- 在`01外部指标.py`中实现三个函数：`calc_JC`、`calc_FM`、`calc_Rand`。
- 输入：参考簇`y_true`与聚类簇`y_pred`，类型为`ndarray`；输出：对应指标的浮点值。

## 解决方法（如何做）
- 两两枚举样本对 `(i, j), i < j`，统计四类计数：
  - `a`: 参考同簇且聚类同簇。
  - `b`: 参考不同簇，聚类同簇。
  - `c`: 参考同簇，聚类不同簇。
  - `d`: 参考不同簇且聚类不同簇。
- 根据计数按公式计算指标：
  - `JC = a / (a + b + c)`
  - `FM = sqrt( (a / (a + b)) * (a / (a + c)) )`
  - `Rand = (a + d) / (n * (n - 1) / 2)`，其中`n`为样本数。
- 边界处理：若分母为`0`，返回`0.0`，避免浮点异常。

## 代码风格（ACM-ICPC）
- 简洁命名与直接条件判断：`yt`（y_true）、`yp`（y_pred）、`n`（样本数）。
- 去除多余布尔中间变量，条件表达式直接在`if`分支中书写。
- 使用标准库`math.sqrt`进行平方根计算。

## 复杂度与正确性
- 时间复杂度：`O(n^2)`，两两枚举样本对；空间复杂度：`O(1)`。
- 计数与公式与题面一致，示例测试输出匹配期望值。

## 示例测试
- 输入：
  - `y_true = [0, 0, 0, 1, 1, 1]`
  - `y_pred = [0, 0, 1, 1, 2, 2]`
- 期望输出：`JC = 0.285714`，`FM = 0.471405`，`Rand = 0.666667`

## 公式小结
- `JC = a / (a + b + c)`：度量同簇一致性占比。
- `FM = sqrt( (a/(a+b)) * (a/(a+c)) )`：几何平均兼顾准确率与召回率风格的同簇一致性。
- `Rand = (a + d) / (n*(n-1)/2)`：整体一致性比例（同簇与不同簇都考虑）。

## 关键实现片段（风格示例）
```python
import numpy as np
import math

# JC
yt = np.asarray(y_true); yp = np.asarray(y_pred); n = len(yt)
a = b = c = d = 0
for i in range(n):
    for j in range(i + 1, n):
        if yp[i] == yp[j] and yt[i] == yt[j]: a += 1
        elif yp[i] == yp[j] and yt[i] != yt[j]: b += 1
        elif yp[i] != yp[j] and yt[i] == yt[j]: c += 1
        else: d += 1
JC = 0.0 if (a + b + c) == 0 else a / (a + b + c)

# FM
FM = 0.0 if (a + b) == 0 or (a + c) == 0 else math.sqrt((a/(a+b)) * (a/(a+c)))

# Rand
tot = n * (n - 1) // 2
Rand = 0.0 if tot == 0 else (a + d) / tot
```
