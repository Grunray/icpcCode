# 02内部指标题解与实现说明

## 题目核心点
- 评估聚类的内部指标：`DBI`（Davies–Bouldin 指数）与 `DI`（Dunn 指数）。
- 不依赖参考标签，通过簇内紧凑性与簇间分离度衡量聚类质量。

## 你要做什么
- 在`02内部指标.py`中实现`calc_DBI`和`calc_DI`函数。
- 输入：`feature`为样本特征（`ndarray`），`pred`为聚类后的簇标记（`ndarray`）。
- 输出：对应的指标浮点值，符合示例测试。

## 解决方法
- `DBI`（越小越好）：
  - 对每个簇`i`：计算质心`μ_i`与簇内到质心的平均距离`S_i`。
  - 对每个`i`，求`max_{j≠i} R_ij`，其中`R_ij = (S_i + S_j) / ||μ_i - μ_j||`。
  - `DBI = (1/k) * Σ_i max_{j≠i} R_ij`。
- `DI`（越大越好）：
  - 计算每个簇的直径`diam(C_l)`（簇内最远两点的距离）。
  - 计算不同簇之间的最短距离`d_min(C_i, C_j)`（跨簇两点之间的最短距离）。
  - `DI = min_{i≠j} d_min(C_i, C_j) / max_l diam(C_l)`，只有两个簇时即为`d_min / max_diam`。
- 距离均使用欧氏距离（`L2`）。
- 边界处理：
  - 少于两个簇返回`0.0`；簇单点时`S_i=0`，直径为`0`。
  - 质心重合导致分母为`0`时，`DBI`该项设为`+inf`使整体变大（更差）。
  - `DI`若`max_diam=0`或无法得到`d_min`则返回`0.0`。

## 复杂度
- `DBI`：质心与均值计算`O(n)`；`R_ij`两两簇比对`O(k^2)`。
- `DI`：簇内直径计算`O(Σ m_l^2)`；跨簇最短距离`O(Σ m_i m_j)`。

## 示例测试
- 输入：
  - `feature = [[3,4],[6,9],[2,3],[3,4],[7,10],[8,11]]`
  - `pred = [1,2,1,1,2,2]`
- 期望输出：`DBI = 0.204765`，`DI = 2.061553`

## 关键实现片段（ACM-ICPC 风格）
```python
import numpy as np
import math

# DBI
X = np.asarray(feature, dtype=float); y = np.asarray(pred)
labs = np.unique(y); k = len(labs)
# 质心与簇内均距
cents, S = [], []
for lb in labs:
    Ci = X[y == lb]
    mu = Ci.mean(axis=0); cents.append(mu)
    S.append(0.0 if len(Ci) <= 1 else float(np.linalg.norm(Ci - mu, axis=1).mean()))
# R_ij 最大值并平均
cents = np.stack(cents); S = np.asarray(S)
D = []
for i in range(k):
    mx = 0.0
    for j in range(k):
        if i == j: continue
        dij = np.linalg.norm(cents[i] - cents[j])
        if dij == 0.0: mx = float('inf'); break
        r = (S[i] + S[j]) / dij
        if r > mx: mx = r
    D.append(mx)
DBI = sum(D) / k

# DI
# 直径
diams, clus = [], []
for lb in labs:
    Ci = X[y == lb]; clus.append(Ci)
    m = len(Ci)
    if m <= 1: diams.append(0.0)
    else:
        md = 0.0
        for i in range(m):
            for j in range(i + 1, m):
                d = float(np.linalg.norm(Ci[i] - Ci[j]))
                if d > md: md = d
        diams.append(md)
# 簇间最短距离
dmin = float('inf')
for i in range(k):
    for j in range(i + 1, k):
        Ai, Aj = clus[i], clus[j]
        for p in range(len(Ai)):
            for q in range(len(Aj)):
                d = float(np.linalg.norm(Ai[p] - Aj[q]))
                if d < dmin: dmin = d
DI = 0.0 if dmin == float('inf') or max(diams) == 0.0 else dmin / max(diams)
```
