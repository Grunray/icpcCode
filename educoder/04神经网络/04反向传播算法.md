# 04反向传播算法

## 题目核心点
- 问题：实现前向传播、反向传播与训练，使用鸢尾花数据进行分类。
- 输入：特征 `X∈R^{m×4}`，标签 `Y`（One-Hot，三类）。
- 输出：训练得到参数 `(W0,B0,W1,B1)` 并用于预测，准确率≥90%。

## 解决方法
- 模型结构：`4 → H → 3`，隐藏层与输出层均使用 `sigmoid` 激活。
- 前向传播：
  - `Z1 = X·W0 + B0`，`A1 = σ(Z1)`；
  - `Z2 = A1·W1 + B1`，`A2 = σ(Z2)`。
- 反向传播（平方误差思想）：
  - 输出残差：`D2 = (A2 − Y) ⊙ σ'(Z2)`；
  - 隐层残差：`D1 = (D2·W1^T) ⊙ σ'(Z1)`。
- 参数更新（学习率 `α`）：
  - `W1 ← W1 − α·A1^T·D2`，`B1 ← B1 − α·sum(D2)`；
  - `W0 ← W0 − α·X^T·D1`，`B0 ← B0 − α·sum(D1)`。

## 复杂度分析
- 设样本数 `m`、特征维度 `n=4`、隐藏维度 `h`、输出维度 `c=3`、迭代 `T`。
- 训练：每轮 `O(m·(n·h + h·c))`，总计 `O(T·m·(n·h + h·c))`。
- 预测：`O(m·(n·h + h·c))`。

## 关键要点
- 残差计算基于 `σ'(z)=σ(z)(1−σ(z))`，与模板保持一致。
- 偏置更新对批次残差逐列求和，与维度对齐（`1×h`、`1×c`）。
- 采用 Xavier 风格初始化，提升训练稳定性与收敛速度。

## 使用说明
- 用数据 `X,Y` 训练：调用 `bp_train(X, Y, n_hidden, maxcycle, alpha, n_output)`。
- 预测：前向计算 `A2`，取最大值索引为类别。测试脚本会据此评估准确率。
