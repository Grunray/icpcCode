# 03从频繁项集中挖掘关联规则

## 题目核心点
- 问题：从频繁项集中挖掘满足最小可信度的关联规则。
- 输入：数据集、最小支持度、最小可信度。
- 输出：规则列表 `(前件, 后件, 可信度)`。

## 解决方法
- 使用 Apriori 先求频繁项集与其支持度：`apriori(dataset, minsupport)`。
- 规则右侧候选集合：对频繁项集 `freqSet` 生成单元素集合 `H1`。
- 可信度计算与剪枝：`conf = supportData[freqSet] / supportData[freqSet - conseq]`，保留 `conf ≥ minConf`。
- 递归扩展右侧：若 `|freqSet| > m+1`，用 `aprioriGen(H, m+1)` 扩展更大后件并继续剪枝与递归。
- 汇总所有通过阈值的规则为结果列表。

## 复杂度
- 频繁项集挖掘成本取决于候选规模与事务数，通常较高；
- 规则生成在每个频繁项集上递增扩展右侧，成本与项集大小与通过剪枝后的候选规模相关。

## 实现要点
- 仅在模板 Begin/End 内实现 `generateRules`，不改动外部结构。
- 在函数内部实现可信度计算与递归扩展，避免外部函数潜在拼写问题影响流程。
- 返回所有满足最小可信度的规则列表，元素类型为 `(frozenset, frozenset, float)`。
