# 02信息熵与信息增益

## 题目核心点
- 题目说什么：实现三个函数，分别计算信息熵、条件熵与信息增益，用以度量特征对分类不确定性的降低程度。
- 要我做什么：补全 `calcInfoEntropy`、`calcHDA`、`calcInfoGain` 三个函数，使其基于数据集标签与指定特征列的取值正确输出对应度量。
- 解决方法是什么：
  - 信息熵：统计标签分布，按 `H(D) = -∑ p_i log2 p_i` 计算。
  - 条件熵：对给定特征值 `v`，取满足 `A=v` 的样本子集，按同样公式得到 `H(D|A=v)`。
  - 信息增益：对特征列所有唯一值加权条件熵，`H(D|A) = ∑_v P(A=v) H(D|A=v)`，再取 `g(D,A) = H(D) - H(D|A)`。

## 知识要点
- 信息熵（Entropy）：刻画随机变量不确定性，概率越平均，熵越大。
- 条件熵（Conditional Entropy）：在条件 `A` 给定时，标签 `D` 的不确定性。
- 信息增益（Information Gain）：使用特征 `A` 后，标签不确定性的减少量；ID3 用其选择划分特征。

## 解题思路与步骤
1. `calcInfoEntropy(feature, label)`：
   - 将 `label` 转为 `ndarray`，统计各类别计数与概率；
   - 用 `np.log2` 计算对数，按公式累加得到熵并返回。
2. `calcHDA(feature, label, index, value)`：
   - 过滤出满足 `feature[:, index] == value` 的样本；
   - 若子集为空返回 `0.0`，否则统计子集标签分布并计算熵。
3. `calcInfoGain(feature, label, index)`：
   - 先求总熵 `H(D)`；
   - 遍历该特征列的所有唯一值 `v`，计算 `P(A=v)` 与 `H(D|A=v)` 并加权求和；
   - 返回 `H(D) - H(D|A)`。

## 复杂度
- 设样本数为 `N`、特征列唯一值数为 `K`。
- 信息熵：`O(N)`（统计标签分布）。
- 条件熵：一次子集计算 `O(N)`，用于某个 `v`。
- 信息增益：`O(N + K*N_v)`，其中 `N_v` 为各子集大小，整体线性级。

## 示例测试
- 输入：
  - `feature = [[0,1],[1,0],[1,2],[0,0],[1,1]]`
  - `label = [0,1,0,0,1]`
  - `index = 0`
- 计算：
  - 总熵 `H(D) ≈ 0.97095`
  - 条件熵 `H(D|A) ≈ 0.55098`
  - 信息增益 `g(D,A) ≈ 0.41997`
- 预期输出：`0.419973`（与平台示例一致）。

## 实现风格
- 代码采用 ACM-ICPC 风格：变量命名简洁、逻辑集中、边界处理明确（空集返回 `0.0`）。
